# UI/UX & Web Interaction Design Portfolio

本專案收錄運用 **Figma** 規劃之互動原型設計，涵蓋「日系風格電商平台」與「建設公司企業形象官網」，著重於使用者旅程動線優化、介面資訊架構與互動組件設計。

---

## 專案一：日系服飾電商平台 (Japanese Cute Fashion Store)

* **設計定位**：針對年輕消費族群設計之日系服飾購物體驗，強化商品視覺張力與直覺結帳動線。
* **核心設計亮點**：
  * **購物結帳動線優化 (Checkout Flow)**：減少非必要表單步驟，提升結帳轉換率與流暢度。
  * **組件化設計系統 (Design System)**：規範統一的按鈕狀態、卡片佈局與排版階層。
* **[👉 點此查看 Figma 互動原型 (Interactive Prototype)](https://www.figma.com/make/0fat2bE5CQM8RYwuVWsNJN/Japanese-Cute-Fashion-Store?t=hfBzbtcQMiSUB59o-1&preview-route=%2Fcheckout)**

## 專案二：建設公司品牌形象官網 (Construction Corporate Website)

* **設計定位**：傳遞企業品牌信任感、ESG 永續經營理念與建案作品展示之現代化形象網站。
* **核心設計亮點**：
  * **清晰的資訊階層 (Information Hierarchy)**：將繁雜的建案資訊、企業願景與聯絡表單模組化呈現。
  * **大氣沉穩之視覺佈局**：採用現代留白與多媒體排版，兼顧視覺質感與使用者易讀性。
* **[👉 點此查看 Figma 互動原型 (Interactive Prototype)](https://www.figma.com/make/9PKMcb1FeRMAtmhr9QuoV8/%E5%BB%BA%E8%A8%AD%E6%A5%AD%E7%B6%B2%E7%AB%99%E8%A8%AD%E8%A8%88?t=2INkiDE7WmLt0dYw-1)**
